# 鍵群:僅雙手對稱的鍵池子集(只沿「排」切,不做單手、不做自由組合)

**Status:** accepted（2026-07-31 修訂：鍵群軸由「排 + 指混用」收斂成純「排」，並新增數字排）

**鍵群(Key Group)** 是 `compileChart` 的 config 輸入(`CompileConfig.keyGroup`),把鍵指派的可用鍵池限縮到一個**預設子集**,供針對性打字練習。實作 = `buildPool(hand, keyGroup)` 依「排過濾」回傳較小的池,`assignKeys` 其餘機制(教學權重 D'Hondt 攤平、可玩性硬底線、determinism)原封不動。刻意約束:鍵群**一律雙手對稱**(兩手都保有鍵)、且僅開放一小組**固定預設**——`all`(全鍵,四排)/ `home` / `top` / `bottom` / `number`,不支援單手、不支援任意勾選。

## 為何只沿「排」切(修訂)

原版另有依手指切的群(`index-middle` / `ring-pinky`)與跨兩排的 `home-top`。實際練習下來:**跨排的難度落差(手要離開家排位、整組肌肉記憶重建)遠大於跨指**,混軸的清單既難挑也練不出對比。收斂成「全鍵 + 四個單排」後,每個選項恰好對應一種可獨立練成的姿勢,且每手鍵數一致(5 鍵),清單自解釋。

**數字排**是為此新增的第四排(每手 `1234`+內側 `5` / 內側 `6`+`7890`),Beat Saber 沒有對應的列——它只從教學權重(最低,全鍵下約佔 8%)與 `number` 鍵群進入譜面。

代價,已接受:舊鍵群不存在了,`bestKeyGroup` 落在舊值的成績無法解讀 ⇒ `SCORES_VERSION` 升 2、整庫作廢重來(全鍵鍵池 15→20 鍵,舊的調整後準確率本來也不可比)。

## 為何記錄

這條範圍界線違反直覺、且會擋掉未來「順手加功能」的衝動:

1. **不做單手鍵群**:初看「只練左手」是很自然的需求,issue 原本也列了。但實測需求為「正常練習用鍵群都有雙手」;而單手會逼出「顏色→手」的衝突(某手在群內無鍵),得在「回退整池 / 鍵群凌駕顏色 / 濾掉另一手音符」間裁決,每條都動到 CONTEXT「手」語義或 judge 準確率分母。**堅持雙手對稱 → 這整個衝突不存在**:永不空手池、不濾音符、不改分母、顏色→手不變。
2. **不做自由組合**:不開放任意 `{banks, fingers}` 或逐鍵勾選,只給固定列舉。避免組合爆炸與極小池的可玩性崩壞,也讓 fixtures 可窮舉。

## 關鍵推理

- 以「縮小 `buildPool` 產出」實作,現有的可玩性降級(同手手指全被佔 → `candidates = pool`)天然變成「在鍵群內放寬」——不會借群外鍵,取捨自動正確。
- determinism 延伸涵蓋鍵群維度:同一 (譜+難度+鍵群) 永得同一組指派;無 RNG。
- `all` 為預設且等同無限制 → 與 issue 11 現況位元級相同,不回歸既有分布/覆蓋成果。
- 鍵群影響**編譯**,故 UI 落在難度選擇畫面(編譯前),非 highway 內的即時滑桿;鍵群本身不需 highway 改動(只渲染 chart 出現的鍵)——但數字排是新的第四排,highway 的 `KEY_LAYOUT` / `ROWS` / `rowY` 得跟著長一列(格線由 3 列變 4 列、整盤重新置中)。

## 被否決 / 排除

- **單手鍵群(只左手/只右手)**:見上;連帶排除為它而生的「鍵群凌駕顏色」與「濾掉另一手音符」兩種機制。
- **任意 `{banks, fingers}` / 逐鍵自訂鍵群**:無此需求,徒增複雜與可玩性風險。
- **逐字母字表 / 單字練習**:那是詞庫不是鍵群,out of scope。
- **依表現自適應調整鍵群**:本 issue 只做玩家手動選。
- **依手指切的鍵群(`index-middle` / `ring-pinky`)與跨兩排的 `home-top`**:2026-07-31 移除,見〈為何只沿「排」切〉。
- **讓單排鍵群的係數反映該排難度**(如數字排係數 > 家排):係數的語義是「練了鍵盤的多少」而非「有多難」,四排池大小相同就該同係數。要獎勵難排,該加的是別的軸(如難度加成),不是把兩件事塞進同一個乘數。

## 連帶影響

- `CompileConfig` 加 `keyGroup?`;`assignKeys`/`buildPool` 收之。keyAssignment 仍純函式、fixtures 可測、無新 I/O。
- 持久化:設定層(issue 12)由「純數值」擴成「數值 + 列舉」,鍵群存同一 `beat-typer:settings` blob,值不合法回退 `all`。
- CONTEXT 新增「鍵群」詞;「手」定義不變。
